发送比特币前如何核对地址：网络、剪贴板与地址混淆风险

比特币地址不是收款人的姓名。转账前，最重要的是确认你拿到的是对方当前提供的完整地址、你发送的是 Bitcoin 主网资产，并且钱包最终确认画面仍显示相同地址。只看地址开头和结尾并不足够。[1]

先分清事实与操作建议

事实：Bitcoin.org 提醒，比特币交易通常无法撤销；恶意软件可能在复制粘贴后替换剪贴板中的地址，地址投毒也会制造首尾相似的记录诱导误复制。[1]

建议：以下检查是降低误操作概率的流程，并不能证明设备没有恶意软件、收款人身份真实，或交易一定可追回。

发送前逐步核对

  1. 确认资产和网络。收款方明确要求 BTC 与 Bitcoin 网络；不要仅凭代币名称或钱包图标推断网络兼容。若平台要求其他网络，暂停并在该平台官方说明中核对。
  2. 从独立可信渠道取得地址。最好直接向收款方确认当前地址；不要从陌生私信、搜索广告或旧交易记录推断地址仍有效。
  3. 粘贴或扫码后比对完整地址。在发送钱包输入后，检查整个字符串；二维码也应在钱包显示目标地址后核对。Bitcoin.org 特别提示不要只比对首尾字符。[1]
  4. 留意剪贴板篡改和相似地址。若地址意外变化、联系人地址与历史交易近似但不相同，取消操作，重新从独立来源获取。历史记录可能包含地址投毒者的相似地址。[1]
  5. 在最终确认页再次核对。逐字检查地址、金额、资产/网络及钱包显示的费用。Bitcoin Core 的发送接口把目标地址和 BTC 金额作为明确参数；地址格式可用性不等于接收者身份已认证。[3]
  6. 特殊情形暂停。若对方临时更换地址、催促、承诺退款或要求保密，通过已知的另一渠道确认；不确定时不要发送。不要向任何人透露恢复短语或私钥。[1]

发送前核对清单

  • 收款人身份通过独立渠道确认？
  • 明确是 BTC 与正确 Bitcoin 网络？
  • 完整地址在输入后及最终确认页一致？
  • 没有仅凭历史记录、首尾字符或陌生二维码判断？
  • 金额、费用和接收平台要求已自行核对？

如果是你自己评估后决定的较大转账，可以考虑先进行小额测试；这会产生另一笔交易和费用，不能替代地址核验，也不保证收款方身份正确。
